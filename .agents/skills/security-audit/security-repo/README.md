# opencollective-security layout (skill copy)

Live files are in [opencollective/opencollective-security](https://github.com/opencollective/opencollective-security). This directory is a matching template for the skill tree.

`harness/index.json` starts empty and is patched with `scripts/patch-index.cjs`.

Mail ingest/send for bounty reports is the local `dashboard/` app in the live repo. The worker contract file documents on-disk layout only.

See that repository's README for architecture, dashboard mail workflow, labels, and fingerprints.
